kill-port-now vs kill-port.

kill-port-now uses Rust to make port cleanup ~3,000x faster than kill-port@2.0.1 in this local macOS benchmark. The dataset also includes the JS fallback, targeted lsof, macOS netstat, and TCP check-only paths.
